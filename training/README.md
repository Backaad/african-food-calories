# Training

Trains the dish classifier, measures it, and exports it for the phone.

| File | What it is |
|---|---|
| [`notebooks/train_classifier.ipynb`](notebooks/train_classifier.ipynb) | The notebook to run on Kaggle or Colab (GPU). Generated by `build_notebook.py`. |
| [`run.py`](run.py) | The steps: `prepare`, `train`, `finish` (evaluate + export), or `all`. |
| [`config.yaml`](config.yaml) | Image size, class threshold, models, epochs, learning rates. |
| [`config_smoke.yaml`](config_smoke.yaml) | Tiny settings for the CI run on real data (checks the pipeline, not the accuracy). |
| `afctrain/prepare.py` | Downloads and assembles the images (Commons, other foods, CamerFood10 crops), removes duplicates, chooses the classes, splits. |
| `afctrain/camerfood.py` | Crops each dish out of CamerFood10 plates using their masks. |
| `afctrain/model.py` | Input pipeline, MobileNetV3 / EfficientNetV2 models, training, distillation. |
| `afctrain/evaluate.py` | Refusal threshold, per-dish accuracy, confusion matrix. |
| `afctrain/export.py` | TensorFlow Lite float16 export and parity check. |

## How it works

1. **Images.** Each catalogue dish gets the files of its Wikimedia Commons
   categories (licence checked per file; title searches and Openverse are left
   out because they are noisy). CamerFood10 plates are cropped around each dish
   (`min_area` 10 % of the plate). Other foods (`data/other_foods.yaml`) form the
   class `other`. Near-identical images are removed; an image filed under two
   dishes is dropped.
2. **Classes.** A dish with at least `min_images` (150) images is a class.
   Dishes with fewer images are put in `other`: the model must answer "dish not
   recognised" for them, and the user picks them from the list. Exception:
   dishes that look like a class (`lookalikes_not_other`: banku, kenkey, amala,
   pounded yam, which look like fufu and ugali) are left out entirely, because
   learning them as `other` taught the model to refuse fufu and ugali (run 1).
   The model may then name fufu or ugali for them; the user corrects it.
3. **Split.** Train 70 %, validation 15 %, test 15 %, decided by a hash of the
   photo, so all crops of one CamerFood10 photo land in the same split.
   CamerFood10's own test images stay in the test set.
4. **Training.** MobileNetV3-Large pretrained on ImageNet: the new head is
   trained first, then the top layers are fine-tuned. Classes are weighted by
   inverse frequency. Optional: an EfficientNetV2-S teacher is trained, then
   distilled into a copy of the student; the distilled model is kept only if it
   does better on validation.
5. **Refusal.** The app shows a dish only if its probability reaches a threshold
   and it is not `other`. The threshold is chosen on validation (most correct
   answers), never on test.
6. **Measures.** On the test set only: final accuracy, per-dish accuracy and
   precision, confusion matrix, refusal rate on known dishes, wrong acceptance
   of other foods, results per source. There are no "real-life" photos yet;
   when there are, they must be measured separately.
7. **Export.** TensorFlow Lite with float16 weights; the test set is run through
   both models and their top-1 agreement and probability differences reported.

## Run it

Kaggle or Colab: open the notebook, turn the GPU on, *Run all*. Locally:

```bash
pip install tensorflow -r training/requirements.txt -r data/requirements.txt
python training/run.py all --work /tmp/afc            # add --teacher, --no-camerfood
python -m pytest -q training/tests                    # unit tests + a CPU smoke test
python training/build_notebook.py                     # after editing the notebook builder
```

## Licence of the model

A model trained with CamerFood10 is released under **CC BY-NC 4.0**
(non-commercial), because CamerFood10 is a training-only source whose image
copyright is not cleared (`data/sources.yaml`). `model_info.json` records it.
CamerFood10 images are never copied out of the machine that trains: the
notebook keeps them in `/tmp` and the results archive contains no image.
